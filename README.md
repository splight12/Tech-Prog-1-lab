# Лабораторная работа №1

## Описание работы

---

Программа на Python, которая определяет, какая операционная система установлена на компьютере (Linux или Windows), и собирает базовую информацию о ней.
Все полученные данные автоматически сохраняются в файл `system_info.json`.

---

## Используемые модули

### Из стандартной библиотеки Python:
* 'os' — узнать пути к файлам.
* 'platform' — узнать версию Python, архитектуру процессора и параметры ОС.
* 'getpass' — узнать имя текущего пользователя.
* 'urllib.request' — сделать запрос в интернет и узнать свой внешний IP.
* 'pwd' (только для Linux) — прочитать список всех пользователей из файла '/etc/passwd'.
* 'json' — красиво сохранить результат в '.json' файл.

### Внешняя библиотека:
* 'psutil' — модуль для сбора информации о железе (нагрузка на процессор, память, службы Windows).

В самом Python нет встроенных функций, чтобы посмотреть загрузку процессора, размер файла подкачки или список запущенных служб в Windows. 
Psutil может напрямую запрашивать эти данные у операционной системы, не используя командную строку.

---

## Собираемые параметры

Все данные сохраняются в json-файл 'system_info.json', сохраняющийся в ту же папку с кодом

### 1. Общие для любой системы:
* 'system' — какая ОС установлена.
* 'python_version' — версия Python, в которой запущен скрипт.
* 'user' — имя пользователя, который запустил программу.
* 'architecture' — разрядность системы.
* 'remote_ip' — публичный IP-адрес в интернете.

### 2. Только для Linux:
* 'distribution' — название дистрибутива.
* 'load_average_15min' — средняя загрузка процессора за последние 15 минут.
* 'pagefile_total_gb' — размер файла подкачки в гб.
* 'all users' — список всех пользователей, зарегистрированных в системе.

### 3. Только для Windows:
* 'win_build' — номер сборки Windows.
* 'system_drive' — системный диск.
* 'running_services' — сколько служб Windows работает прямо сейчас.
* 'pagefile_total_gb' — размер файла подкачки в гб.
* 'all users' — список пользователей, вошедших в систему.
